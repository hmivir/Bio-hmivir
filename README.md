## 🚀 Current Projects
- **Diabetes Prediction with ML**: Develop a machine learning model to predict the likelihood of diabetes based on medical records. The project covers the full pipeline from exploratory data analysis (EDA), feature engineering, model training, and evaluation to deploying a real-time prediction web app using Streamlit/FastAPI..
- **Immunotherapy for lung cancer**:Building a machine learning model to predict the effectiveness of immunotherapy treatments for lung cancer by combining clinical data, genomics, and CT scan (TAC) images. This project is currently in progress and aims to advance personalized medicine by providing insights into treatment efficacy, ultimately improving treatment decision-making.
